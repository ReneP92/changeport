# Brand

The ChangePort mark is a change log: three log rows, with the newest change
in the accent color.

| File | Use |
| --- | --- |
| `changeport-logo.svg` | Mark and wordmark on light backgrounds |
| `changeport-logo-dark.svg` | Mark and wordmark on dark backgrounds |
| `changeport-mark.svg` | Mark alone: favicons, app icons, avatars |

- Colors: ink `#0B1F33`, accent teal `#0D9488`, white `#FFFFFF` on dark.
- Wordmark: Space Grotesk SemiBold (SIL Open Font License), letter-spacing
  -0.02em, outlined so it renders without the font installed.
- Lockup: the mark is 1.3 times the wordmark's font size, with a gap of
  0.35 times the font size.
